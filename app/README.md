# BOI local PDF filler

ติดตั้ง dependency ครั้งแรกจากโฟลเดอร์ `app` ด้วย `python -m pip install -r requirements.txt` จากนั้นรัน `run_app.bat` หรือ `python app.py` แล้วเปิด http://127.0.0.1:5000

ถ้าต้องการเพิ่มเอกสารหรือแก้ไขระบบในอนาคต ให้ดู [MAINTENANCE.md](MAINTENANCE.md)

ลำดับการใช้งานคือ เลือกเอกสาร > กรอกข้อมูล > ตรวจสอบ > Export แอปทำงานเฉพาะในเครื่องนี้ และใช้ PDF แบบฟอร์มใน `documents/` เป็นแม่แบบ จากนั้นเติมข้อมูลเฉพาะเอกสารที่เลือกและรวมเป็น PDF เดียว

Public checkout จะใช้ `config/documents.example.json` ซึ่งไม่มีเอกสารจริงและไม่มี PDF บริษัท จึงใช้สำหรับอ่าน source และรัน tests ได้ แต่ยัง Export เอกสารจริงไม่ได้จนกว่าจะติดตั้ง private document pack ในเครื่อง

แอปนี้ตั้งใจให้ใช้เฉพาะเครื่องนี้ที่ `127.0.0.1` ไม่ควรเปิด port ให้เครื่องอื่นหรือ deploy ขึ้น Internet โดยตรง ข้อมูลระหว่างกรอกจะเก็บใน SQLite server-side ที่ `data/sessions.sqlite3` และจะคงอยู่จนกดปุ่ม `ล้างข้อมูล` โดยไม่ถูกเก็บใน browser cookie

โฟลเดอร์ `documents/` เป็น PDF แม่แบบ private ของผู้ใช้แต่ละราย ไม่ควร commit ขึ้น GitHub ส่วน `data/`, `config/documents.json` และไฟล์ PDF ถูกกันไว้ใน `.gitignore` แล้ว

สำหรับการใช้งานจริง ให้เก็บ config ไว้ที่ `config/documents.json` และตั้ง `BOI_DOCUMENTS_CONFIG=config/documents.json` จากโฟลเดอร์ `app` โดยห้ามใส่ค่า config จริงหรือ PDF private ใน repository สาธารณะ

ถ้าต้องการกำหนด secret key แบบคงที่ ให้ตั้ง environment variable `BOI_SECRET_KEY` นอก repository ก่อนรันแอป หากไม่ตั้ง ระบบจะสุ่ม key ใหม่ในหน่วยความจำเมื่อเริ่มโปรแกรม

หน้าเว็บมี Header กลาง, Progress ที่ใช้ย้อนกลับไปขั้นก่อนหน้าได้ และปุ่มรูปเฟืองสำหรับเปิด Settings แบบ Pop-up เพื่อกำหนดฟอนต์ ขนาดฟอนต์ สีหลัก และ Light/Dark/Auto mode ของงานปัจจุบัน

เพิ่มเอกสารใหม่โดยวาง PDF ที่สร้าง Text Field ด้วย Adobe ลงใน `documents/` แล้วเพิ่มรายการและ mapping ใน `config/documents.json` ผู้ใช้ไม่ต้องตั้งค่า mapping เอง ไฟล์นี้เป็น local-only และไม่ควร commit

หน้าเว็บมีตัวเลือกฟอนต์และขนาดฟอนต์ และเหตุผลรายได้น้อยใช้ช่องเดียว ระบบจะแบ่งลงบรรทัดที่หนึ่งและสองให้เอง

ข้อมูลทุกช่องสามารถเว้นว่างได้ วันที่เอกสารและวันที่เริ่มประกอบธุรกิจแสดงและกรอกเป็น `วว/ดด/พ.ศ.` เช่น `01/09/2569` พร้อมปุ่มเลือกวันที่ โดยวันที่เอกสารจะตั้งต้นเป็นวันปัจจุบันเมื่อเปิดฟอร์มครั้งแรก และจะแสดงเป็นวันที่ภาษาไทยใน PDF

ช่องอายุลูกจ้างรับเฉพาะตัวเลข 0–9 และสามารถเว้นว่างได้เช่นเดียวกับช่องอื่น

ชื่อไฟล์ PDF ตั้งต้นเป็น `หนังสือบริษัท ชื่อบริษัท.pdf` และสามารถแก้ไขได้ใน Progress 4 ก่อนดาวน์โหลด

หลัง Export ข้อมูลจะยังอยู่เพื่อให้ตรวจสอบหรือ Export ซ้ำได้ ให้กดปุ่ม `ล้างข้อมูล` เมื่อจบงานและต้องการลบข้อมูล session ปัจจุบัน

หน้า Form แสดงช่องกรอกแยกตามเอกสารด้วยรายการเอกสารฝั่งซ้ายและฟอร์มฝั่งขวา ชื่อหัวข้ออยู่ด้านซ้ายและช่องข้อมูลอยู่ด้านขวา ฟิลด์ที่ใช้ข้อมูลกลางร่วมกันจะ sync ค่าให้กันอัตโนมัติ แล้วรวมกลับเป็นข้อมูลกลางชุดเดียวก่อน Review และ Export
